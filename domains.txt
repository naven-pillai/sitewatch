# A homepage 200 can be served from the CDN edge straight through a database
# outage. These routes run a real Postgres read and return 503 when it fails,
# so they catch what the checks above structurally cannot.
#
# Per-domain checks (robots, www, registration) are already covered by the
# homepage entry above, so these skip them.
